# Remotion Player preview project

Standalone Next.js preview app. Templates are listed in `app/templates.tsx` (add a template there only); a fixed sidebar on desktop and a collapsible drawer on mobile select between them.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Assets

Sample images live in `public/book-assets/` (used by the carousel and mosaic templates' default props). Font: `public/fonts/Cairo-Bold.ttf`.

Remotion package versions are pinned to 4.0.539.
